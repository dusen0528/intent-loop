# Intent Loop

**작업의 목표뿐 아니라, 그 과정에서 지켜야 할 조건도 남도록.**

긴 작업의 압축·재개에 대비해 사용자 제약을 별도 보존하는 지침·훅 팩입니다. 매 사용자 메시지의 제약 검토를 제출해야 새 작업 도구를 실행할 수 있습니다.

```text
사용자 메시지 → 검토 필요 → 추가·변경·철회 또는 변경 없음 제출 → 작업
                    │
              압축·재개 후에도 유지
```

## 구성

- `skills/intent-loop/SKILL.md`: 모델용 검토·제출 지침.
- `scripts/review_gate.py`: 제약 저장, 미검토 호출 차단, 재개 복원.
- `hooks/hooks.json`: 네 이벤트의 공용 등록 설정.
- `.codex-plugin/plugin.json`, `.claude-plugin/plugin.json`: 호스트별 매니페스트.
- `tests/test_review_gate.py`: 실제 프로세스·파일 기반 회귀 테스트.

Python 3.10+와 POSIX(Linux/macOS)가 필요합니다. 추가 패키지, 별도 추출 모델, DB, MCP 서버는 없습니다. Windows는 지원하지 않습니다.

## 사용

### Claude Code

압축을 푼 팩 경로를 지정해 새 세션에서 불러옵니다.

```sh
claude --plugin-dir /absolute/path/intent-loop
```

### Codex

팩은 Codex 플러그인 구조를 포함합니다. 마켓플레이스 게시·등록은 하지 않았습니다. 로컬에서 훅만 연결하려면 프로젝트 `.codex/hooks.json`에 이 팩의 `hooks/hooks.json` 항목을 병합하고, 각 command를 다음처럼 실제 절대 경로로 바꿉니다.

```sh
python3 -I /absolute/path/intent-loop/scripts/review_gate.py hook
```

기존 훅을 덮어쓰지 않습니다. Codex `/hooks`에서 정의를 확인하고 신뢰해야 실행됩니다. 지침도 사용할 때는 `skills/intent-loop` 폴더를 해당 호스트의 스킬 위치에 배치합니다. 플러그인으로 로드할 때는 루트 환경변수가 제공되므로 경로 치환이 필요 없습니다.

[Codex hooks](https://learn.chatgpt.com/docs/hooks) · [Claude Code hooks](https://code.claude.com/docs/en/hooks)

팩을 만든 것과 현재 세션에서 활성화한 것은 다릅니다. 이 패키지는 전역 설정을 자동 수정하지 않습니다.

## 동작 범위

| 이벤트 | 동작 |
|---|---|
| UserPromptSubmit | 새 검토 ID와 미검토 메시지 저장 |
| PreToolUse | 미검토 작업 호출 거부. 전용 제출 명령·질문은 이 게이트가 차단하지 않음 |
| SessionStart의 resume·compact | 동일 작업 디렉터리·세션의 제약과 검토 상태 복원 |
| Stop | 미검토 종료를 한 번 막음. 재진입해 종료해도 작업 도구의 잠금은 유지 |

`[]`는 변경 없음의 명시적 제출입니다. 훅이 출력한 전용 명령을 사용합니다. 새 제약·수정·철회에는 미검토 사용자 메시지에서 가져온 실제 출처 구절이 필요합니다. 상세 프로토콜은 [모델 지침](skills/intent-loop/SKILL.md)에 있습니다.

`.intent-review/`에는 세션별 제약과 미검토 메시지가 저장됩니다. Git에 포함하거나 공개하지 마세요. 검토 완료 시 미검토 원문 목록은 비워지지만 제약의 출처 구절은 남습니다. 별개 작업에는 새 세션을 사용하고 호스트의 작업 디렉터리를 고정합니다.

비활성화하려면 호스트에서 이 팩의 훅 등록을 제거하거나 플러그인을 끕니다. 스킬만 제거하면 훅은 남으므로 제출 차단도 계속됩니다. 실행 중에는 상태 파일을 삭제하지 않습니다.

## 검증과 한계

```sh
python3 -m unittest discover -s tests -v
```

회귀 검사는 미제출 차단, 변경 없음, 추가·변경·철회, 출처 검사, 오래된 제출 거부, 연속 메시지 보존, 압축 복원, 질문 경로, 셸 명령 연결 거부를 다룹니다. 다른 경로로 옮긴 패키지의 실행도 점검합니다.

실제 호스트에 설치한 모델 세션의 성능 개선은 아직 측정하지 않았습니다. 검토 절차를 강제하며, 추출의 의미적 정확성이나 정직한 `변경 없음` 판단을 증명하지 않습니다. 매 사용자 턴의 제출 호출에는 비용이 있습니다.

훅을 거치지 않는 호스팅 도구, 기존 실행 프로세스, 상태 파일의 악의적 변조를 통제하는 보안 경계가 아닙니다. 기록된 제약은 실행 권한이나 승인 증명이 아닙니다. 호스트의 기존 권한 검사는 그대로 적용됩니다.

버전 0.1.0, 실험용 패키지. 공개 저장소 게시와 배포 라이선스 선택은 아직 하지 않았습니다.
